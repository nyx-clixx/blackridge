Discord Server Protection

Blackridge is a Discord security bot with configurable anti-raid, anti-nuke, moderation, and member verification tools.

Anti-Nuke

Set separate limits for channel, role, webhook, and moderation activity. Log incidents or respond automatically when an actor crosses a limit.

Anti-Raid

Catch sudden spikes in joins. Use a sensitivity preset or set your own threshold, then choose how to handle qualifying arrivals.

Checkpoint

Score new accounts and flag suspicious joins.

Auto Moderation

Detect spam, repeated messages, and unwanted links.

Verification

Give new members a clear way in with one-click verification or a private image CAPTCHA.

Lockdown

Pause invites, lock channels, and restore recorded settings when an incident ends.

Built for moderation teams

Act from Discord

Clear recent spam with /purge and pull up a member’s recorded warnings, kicks, and bans with /history.

Delegate with Permits

Choose which Discord users and roles can use each moderation command.

Frequently asked questions

How do I add Blackridge to my Discord server?

Add Blackridge to Discord, select a server you manage, and authorize the bot. In the dashboard, choose which protections to enable and check that Blackridge’s role is above the roles it needs to moderate.

How do I give verified members access?

In Discord, give the Verified Role access to member channels. Keep the verification channel visible to newcomers and publish the panel from Blackridge.

Can I monitor a server before enforcing actions?

Yes. Choose Log Only for a protection rule and review the detections in Security Logs before changing its response.

What can a server backup restore?

Backups can restore supported server settings and recreate eligible roles and channels. See the documentation for recovery limits.
